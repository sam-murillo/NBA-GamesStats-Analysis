# NBA-GamesStats-Analysis
Project Purpose: The purpose of this project is addre is addressing is curiosity about what stats matter in an NBA game and lead to the team winning or losing. My intended audience is NBA and sports fans. The data I am using is a dataset from Kaggle that was scraped from the NBA's website of their official data. The main analytical goal of the project is to show what aspects of the game have a statistical impact on the outcome of the game to show how different actions affect success. In my app, a user should explore and compare how different actions and stats affect the outcomes of games and the success of the team. One important limit of boundary of the project is that the play style of the game of basketball changes over time so there may not be universal strengths but better strategies in the different time periods.

Data access: My data was sourced from Kaggle. Within the Kaggle, I am specifically using the "TeamStatisticsExtended.csv" the link to the Kaggle is: https://www.kaggle.com/datasets/eoinamoore/historical-nba-data-and-player-box-scores/data
